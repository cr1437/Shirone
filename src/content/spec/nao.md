# 友利奈绪

*星之海学园的学生会长。扛着摄像机到处偷拍，把「不讲道理」过成日常的银发少女。*

## ✦ 她是谁

友利奈绪（友利奈緒 / ともり なお / Tomori Nao）是 Key 与 ANIPLEX 联合企划、**麻枝准**担任原作与全话脚本、**Na-Ga** 负责角色原案、**P.A.WORKS** 制作的原创动画《**Charlotte**》的女主角。星之海学园高中一年级学生，学生会会长——准确说，是「被学生会选拔出来履行特殊职责」的那位会长。代表色是雾蓝 <span style="color:#4E739C;font-weight:700">#4E739C</span>。

## ✦ 她的样子

银发、蓝瞳，披肩双马尾；水手服配黑色及膝袜与短靴。脖子上挂着的摄像机几乎不离手，耳朵里常年塞着耳机。

还有一个都市传说级别的设定：她的裙子是「反重力裙」，无论高踢腿还是飞踹，都不会走光。

## ✦ 她的性格

我行我素，性格孤立，不太合群。用能力打架时，在旁人眼里就是单方面殴打别人，于是她在学校里很不受欢迎，常被同学「放学别走」然后群殴一顿——她早就习惯了，也不还手。

本人相当腹黑，能随口编出鬼才信的谎话而面不改色，还总欺负友军。

但真正的她善良、谦和，交涉能力一流，作战布局与计谋无出其右，哪怕从零开始打棒球也能指挥得极出色。她非常温柔体贴，也会照顾人，只是从不明说。还是个货真价实的吃货：喜欢「一拉绳子就会自动加热」的牛舌便当，也爱烤玉米和烤肉；讨厌蔬菜和青椒，却喜欢金针菇酱。

## ✦ 她的能力

她的超能力是**「把自己的身形从他人的视野中消除」**——不是隐身，是让别人看不见她。而且这是不完全的能力，一次只能作用于一个人。

她拿着摄像机明目张胆地偷拍，靠的就是它。至于副作用：能力用多了，会逐渐沦为女配角。

## ✦ 她的故事

哥哥**友利一希**曾是吉他手，拥有让空气震动的能力。家里太穷，加上政府的压力，兄妹俩被母亲卖给科学家做研究。被怀疑也有超能力的奈绪，每天被迫接受「健康检查」，在虚伪的环境里长大，从此不再相信任何人。一年后她逃了出来，遇到「唯一信赖的人」，进入星之海学园，精神已经出了问题的哥哥也得以转院治疗。

她每天都戴着耳机听后摇滚乐队 ZHIEND 的歌——那是她与哥哥共同的喜好。

![星空下的背影](/images/characters/nao-starry.webp "《Charlotte》主视觉")

乙坂有宇堕落放纵的那段时间，她一直用能力跟在旁边。看到他天天吃些不健康的东西，就悄悄给他送沙拉；在他差点堕落到要吸毒时出现，一脚踹碎他混沌的堕落；最后用乙坂步未生前一直做的披萨酱蛋包饭，把他重新拉了起来。后来在有宇和莎拉·谢恩的帮助下，哥哥开始恢复正常，已经能认出她了。

第十一话时间线改变后，她被恐怖组织抓为人质。乙坂有宇在试图解救她与熊耳时意外发动了崩坏能力，整栋建筑塌了下去，熊耳用自己的命换下了他们。

第十二话，当有宇问起凭一己之力如何拯救能力者时，是奈绪提出了那个计划：让他用掠夺能力，夺走全世界能力者的能力。有宇同意，并首先夺走了她的能力——其实这也是她一直以来的愿望：变回普通人。

出发前，她连夜给他做了一本英文会话便笺册。这本单词本后来成了有宇的精神支柱：在他过度使用能力、精神失常到产生幻觉和失忆的时候，唯一记得的，就是有个人跟他约好了，要在他夺走全世界的特殊能力之后回去。

有宇最终在北京市完成使命，被哥哥救回。奈绪在他醒来时流着眼泪笑着迎接他，并自称是他的恋人。

从此，学生会不再需要和超能力者打交道，她的摄像机也不必再记录不开心的事，转而专门记录伙伴们快乐的生活。

## ✦ 名场面与小趣闻

- 名台词「**我是你的恋人！**」——气势十足，毫无铺垫。
- 结局那句：「今后我们来度过满是愉快之事的人生吧！」（「これからは楽しいことだらけの人生にしていきましょう！」）
- 本作的颜艺担当，出现过大量神奇表情（其中一部分是远景崩坏造成的）。
- 执法过程中，她被弓道部长有动用「意念摄像」拍下了内衣照。她天真地认为那种照片不会有人要，得知真有人要之后还特别开心。
- 和西森柚咲站在一起也不逊色的外形，常被不熟的人误认成现役偶像或模特。
- 2015 年世萌夏季季番表演赛优胜；2016 年世萌黄玉项链获得者。
